# PORTFOLIO OS · 设计留学智能规划师

> AI-native Design Education Planning Agent —— 把「我能申请哪里 → 作品集缺什么 → 接下来做什么 → 是否需要专业服务 → 预约/支付」这一整件事，交给一个智能体办完。

**支付宝 · 智能体涌现奖 参赛作品 · 消费新体验赛道** · 1% DESIGN LAB 出品

## 它是什么

不是一个「回答留学问题的聊天机器人」，而是一个把诊断、规划、执行、交易跑完整闭环的设计教育决策与申请执行智能体。

**一支流程走完 7 步：**

1. **背景接入** — 学生画像 + 作品集逐页解析（项目结构、研究证据类型识别）
2. **Portfolio Gap Analysis（核心）** — 五维评估模型（视觉表达 / 研究深度 / 交互与服务 / 叙事完整性 / 技术广度），对照 UAL / RCA 录取参考线，输出「关键差距 / 可提升 / 优势」三级诊断与行动建议
3. **院校匹配** — 冲刺 / 匹配 / 稳妥三档 6 个项目，匹配度评分 + 差距标注
4. **作品集补强方案** — 诊断结论翻译为带工期与优先级的行动线
5. **申请时间线** — 锚定递交窗口的倒计时作战计划
6. **服务预约** — 只推荐与诊断结果直接对应的服务，日历时段预约
7. **支付宝收银台** — 高保真模拟支付确认（演示环境，不产生真实扣款）

## 技术栈

React 18 · Vite · Tailwind CSS v4 · Motion (Framer Motion) —— 纯静态构建，零后端依赖。

> 本仓库为参赛演示：学生、作品集、院校与服务数据均为按真实设计留学咨询逻辑编排的示例数据。

## 本地运行

```bash
npm run build   # 构建
```
